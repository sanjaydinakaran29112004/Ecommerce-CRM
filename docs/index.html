1. Executive Summary & Business Value

EntryKode CRM is a high-performance, enterprise-grade e-commerce operations cockpit. It brings together multi-channel order processing, cryptographic payment reconciliation (Razorpay), physical return inspections (RMA), customer 360 retention intelligence with automated dormancy detection, multi-agent support ticket threads, and cohort marketing into one coherent, reactive dashboard.

Enterprise Architecture Principles

  • Decoupled React SPA & Modular Express API: Scalable micro-module backend architecture paired with an ultra-responsive React 18 + Vite frontend.
  • Deterministic Data Integrity: Zero hardcoded heuristics or artificial metric overrides; all counters are bound 1:1 to MongoDB collections.
  • Sub-second Reactive UX: Optimistic TanStack Query mutations ensuring 0ms perceived latency for task completions and status transitions.
  • Cryptographically Verified Payments & Refunds: Complete Razorpay integration with UTR tracking, official printable settlement receipts, and automated instant gateway refunds.
  • Strict 4-Tier RBAC: Granular permissions partitioning access across Super Admin, Admin, Sales Manager, and Support Manager.

3. Exhaustive Breakdown of All 15 Functional Modules

3.1 Executive Dashboard & Real-Time KPI Analytics Module 1

Serves as the executive flight deck. Displays accurately calculated revenue in INR, total orders, and bound active customer counts (5 active accounts in MongoDB). Features interactive Recharts revenue velocity curves, fulfillment donut charts, debounced global search across all entities, and reactive stock alert notifications with individual dismissal and "Mark all as read" capability.

3.2 Customer 360 & Automated Dormancy Governance Module 2

Comprehensive customer demographic aggregation and retention intelligence. Automatically executes the 1-Year Dormancy Engine: Any customer with no recorded orders or activity for > 365 days is dynamically classified as INACTIVE with an amber dormancy badge (tested with live verified customer Suresh Kumar, CUST-00105, 456 days dormant). Includes slide-over Customer 360 profile drawer and standardized address normalizers.

3.3 Leads & Sales Conversion Pipeline (Kanban) Module 3

Visual drag-and-drop Kanban managing B2B and prospective retail leads through stages: NEW → CONTACTED → QUALIFIED → PROPOSAL → WON / LOST. Automatically converts WON leads into active customer records in MongoDB.

3.4 Product Catalog & SKU Management Module 4

Master catalog management for SKU creation, price definitions, cost analysis, and stock allocations. Implements strict data validations ensuring positive pricing, unique SKU uppercase constraints, and real-time category tagging.

3.5 Warehouse Inventory & Stock Movement Ledger Module 5

Warehouse safety stock monitoring with automated early-warning alerts for items with ≤ 10 units remaining. Backed by an immutable StockMovement ledger recording every restock, sale, return restock, and damaged write-off with delta quantities and staff references.

3.6 Orders, Fulfillment & Delivery Terminal Lock Module 6

Comprehensive order lifecycle pipeline: PENDING → CONFIRMED → PROCESSING → SHIPPED → DELIVERED. Once an order reaches DELIVERED, the "Update" button is permanently hidden and replaced with ✓ Delivered (Finalized) to prevent unauthorized status changes.

3.7 Payment Gateway Integration & Settlement Receipts Module 7

Integrates the official Razorpay Payment Gateway. Built dedicated GatewayReceiptModal.jsx providing an official settlement receipt with verified PAID & SETTLED stamp, Razorpay Transaction ID (UTR reference with 1-click clipboard copy), merchant GSTIN, itemized order breakdown, and browser print capability.

3.8 Returns, Reverse Logistics & Razorpay Refund Gateway (RMA) Module 8

End-to-end Return Merchandise Authorization (RMA) workflow. Supports physical package inspection, evaluation of device condition, instant Razorpay gateway refunds, and clean rejection purge (completely removing rejected items from the active returns dashboard). The "Inspect / Change Verdict" button remains active at all times.

3.9 Customer Support Ticket Threads & Escalations Module 9

Multi-agent customer support ticketing system with chronological conversation history between customers and support staff. Includes an integrated Return Escalation Link with a 1-click Go to Returns ➔ shortcut for quick RMA creation.

3.10 Targeted Marketing Campaigns & 4-Stage Lifecycle Module 10

Customer engagement campaigns across Email, SMS, and WhatsApp. Features full 4-stage lifecycle state transitions: SCHEDULED ↔ ACTIVE ↔ PAUSED ↔ COMPLETED with 1-click action buttons on every campaign card.

3.11 Team Tasks & 0ms Reactive Deliverable Tracker Module 11

Internal task assignment and accountability desk. Built with optimistic local state reconciliation providing 0ms instantaneous checkbox completion toggling, string ID normalization for MongoDB ObjectIds, and active status filtering tabs.

3.12 Business Intelligence, Analytics & Financial Export Module 12

Executive reporting suite offering month-over-month revenue velocity metrics, AOV computations, customer acquisition analytics, and 1-click CSV data export for financial audits.

3.13 Staff, Employees & 4-Tier RBAC Management Module 13

Role-Based Access Control administration covering Super Admin, Admin, Sales Manager, and Support Manager. Allows adding employees, setting credentials, and configuring department permissions.

3.14 System Settings, Security & Field Requirements Box Module 14

Enterprise validation compliance box (FieldRequirementsBox.jsx) deployed across forms: validates password (8–18 chars, upper/lower, number/punct, no spaces/unicode), names (min 3 alphabetic), account numbers (9–18 digits), and 10-digit phone numbers.

3.15 Immutable Audit Logging & Compliance Ledger Module 15

Enterprise audit compliance recording every high-value operation (Logins, Refunds, Order Status Changes, Customer Modifications) with actor details, entity IDs, IP addresses, and timestamps.
